# Mockup · Gestión berry.Glow_py

Mockup navegable del sistema de gestión de la tienda: clientes y cuentas, cálculo de precios
desde dólares y courier, ventas con pagos mixtos, precios especiales, cuotas con fecha, devoluciones y
cambios, saldo a favor con su cuadre, recibos, envíos por encomienda, stock sin movimiento, meta y comisión
de la vendedora y un resumen gráfico para el dueño. Tema claro u oscuro. Es una maqueta para aprobar las pantallas: usa **datos de ejemplo
ficticios** y todo se guarda solo en el navegador de quien lo abre.

Para entrar: «Entrar como Ariel (dueño)» o «Entrar como Jazmín (vendedora)». No pide contraseña.
