# Mockup · Gestión berry.Glow_py

Mockup navegable del sistema de gestión de la tienda: clientes y cuentas, cálculo de precios
desde dólares y courier, ventas con pagos mixtos y recibos. Es una maqueta para aprobar las
pantallas: usa **datos de ejemplo ficticios** y todo se guarda solo en el navegador de quien lo abre.

Para entrar: «Entrar como Dueña» o «Entrar como Caja». No pide contraseña.
